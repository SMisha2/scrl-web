# Фотографии фона ScRl

Сайт использует облегчённые WebP-копии, а PNG остаются запасным вариантом для старых браузеров.

Клади сюда две пары файлов:

- `day.png` и `day.webp` — фон днём.
- `night.png` и `night.webp` — фон ночью.

Важно:
- Имена файлов должны быть ровно такими, как выше.
- Исходник — PNG 1919×1079. WebP должен быть той же картинкой в том же размере.
- После замены PNG пересобери WebP, например через Squoosh или `cwebp -q 86 day.png -o day.webp`.
- Не добавляй руку, интерфейс или рамки — только сам скриншот мира.
- Не растягивай и не обрезай фотографию заранее: сайт поставит её на весь экран с сохранением пропорций.

После загрузки WebP используется как основной фон, а PNG — как запасной. Никакие фильтры, генерация текстур или дополнительные 3D-слои не нужны.
