# Фотографии фона ScRl

Клади сюда две фотографии:

- `day.png` — фон днём.
- `night.png` — фон ночью.

Важно:
- Имена файлов должны быть ровно такими, как выше.
- Формат — PNG.
- Не добавляй руку, интерфейс или рамки — только сам скриншот мира.
- Не растягивай и не обрезай фотографию заранее: сайт поставит её на весь экран с сохранением пропорций.

После загрузки оба файла будут использоваться напрямую как фон. Никакие фильтры, генерация текстур или дополнительные 3D-слои не нужны.
